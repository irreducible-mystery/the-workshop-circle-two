## 3. THE GATE, MEASURED BEFORE COMMITTING — the builder's condition, met

The builder's word came with one condition: gate before committing, and
if it runs red, report rather than pre-exempt. Measured on a scratch
clone with the documents placed in-tree byte-exact at their pins.

**With all three, as originally worded:**

```
pointer gate: 49 docs scanned; 1174 in-scope occurrences; 33 unresolved
  PINBOARD.md                    31
  STATE-OF-THE-RECORD-v2.md       1
  CIRCLE-THREE-CHARTER-DRAFT.md   1
```

The pinboard's thirty-one split cleanly: **twenty-three are hashes and
eight are filenames of zips and documents that are not in the tree.**
That is not a defect in the pinboard. It is a **structural mismatch**: a
pin archive's whole purpose is recording hashes of artifacts that are
not in the tree, and the pointer gate's whole purpose is insisting that
backticked tokens resolve in it. The two designs cannot both be right
about the same file.

**And the record has already ruled on this exact shape.** `CLOSING.md`
§3 measured putting the annex's prose into the gates' DOCS set, found it
would need twenty-four exemptions on day one, and declined — *"a gate
that needs twenty-four exemptions on day one for material nobody can
edit turns its own ledger into the noise its header warns about."*
Thirty-one is more than twenty-four. Committing the pinboard into the
gate's scope was the thing the record declined once already, and neither
seat had noticed the precedent applied.

So the courier's withdrawal and the instrument's measurement point the
same way, for different reasons. This seat records that agreement rather
than leaning on either alone.

**With the pinboard out — the live question:**

```
pointer gate: 48 docs scanned; 1119 in-scope occurrences; 2 unresolved
  CIRCLE-THREE-CHARTER-DRAFT.md   "STATE-OF-THE-RECORD"
  STATE-OF-THE-RECORD-v2.md       "427c88d5…" (the sealed crate zip)
```

Two tokens, both ordinary and both precedented:

- **"STATE-OF-THE-RECORD"** — the charter draft names the state document
  without its extension. The file `STATE-OF-THE-RECORD.md` exists in the
  tree; the token as written matches neither it nor the v2. A near-miss
  on a real file, and the document enters byte-exact so it cannot be
  edited.
- **"427c88d5…"** — the sealed crate's zip pin. The crate is transport
  and lives in no tree by design. The ledger already carries a section
  for exactly this species: *"Artifact SHA-256 pins (full where on
  record, prefix where only the elided form ever reached this side)"*.

**Nothing is committed on that measurement.** Two exemptions are two
exemptions, and the C11 ruling's clause 3 puts any instrument change on
both seats' words. This is the report; the word is the builder's to
