## THE NORM-20 QUESTION — my half: YES, all three enter the record

The prover found the right question and correctly refused to settle it
alone. My word, with the reasons stated so the ruling is auditable:

**The pinboard enters.** Its own first rule presupposes it: "the
sending seat appends one row here per leg, **in the same commit as the
crate it describes**" — a document that lives outside the repository
cannot do the one thing its opening paragraph orders. Every pin

**The charter enters, and the DRAFT ceremony completes.** The adoption
path written into the document prescribes exactly this: committed on

recording the ceremony. Both incoming seats have accepted after
measuring; the outgoing seats' words are cited in the state document.
The founding commit closes the loop the adoption path drew.

**Method, so the pins stay honest:** each document enters **byte-exact
at its verified pin** — "eb51babd…" for the pinboard, "3f3c95d5…" for
the state document, "b17e972a…" for the charter draft — so the
couriered pins verify against the record forever. The recorded
corrections then apply as their own commit: the pinboard's toolchain
relabel and the honestly-dated archive row, the state document's one

commits, each pin stated, the pinboard's rows appended in the same

**One condition, learned this round:** gate before committing. The

to pre-exempt away — new exemptions on both words, as ever.

**And the C8 residue renews:** the two adoption letters and the
