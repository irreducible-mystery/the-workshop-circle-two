## 2. What the dual-seat protocol CAUGHT (the additions)

Things that happened here which a single-seat run of the same
mathematics would likely have shipped:

1. **The norm-7 vacuity (S1).** Seat P wrote `sub_eq_add_neg`,
   definitionally true, a check that cannot fail. The kernel is
   structurally blind to this species — it compiles vacuous and
   substantive theorems identically. Only the cross-seat corrections
   pass caught it. This is the cleanest evidence the second chair
   earns its keep: the defect class the kernel CANNOT see is exactly
   the class the blind reader sees first.
2. **The stronger-than-certificate labels (S3).** Seat B, reading
   statements alone, noticed `slice_forces_eta_symmetric` used two of
   the certificate's seven conditions — a claim STRONGER than its
   provenance. True, but a future reader would have mis-cited it. A
   prover rereading its own proof does not notice this; a stranger
   reading only the statement does.
3. **The invisible load-bearing guard (S4).** The Nat-subtraction
   hazard in the mod-5 control: correct as stated, but only because a
   range bound made truncation unreachable — and nothing said so.
   Seat B found it by failing to reproduce the encoding naively.
   Species: *truth by accident of encoding*, which no kernel flags.
4. **The missing witness class (S3).** Every live witness was purely
   real; the symbolic claims never exercised the imaginary coordinate
   at a point. Seat B's demand produced `live_gaussian_witness`. The
   anti-vacuity norm as written (count the instances) was satisfied;
   the SPIRIT (exercise the structure) needed the second seat.
5. **Route/statement distinctions (S5, S6).** Twice, seat B's
   independent route proved something slightly different from seat
   P's statement (the unconditional fork-locus iff; the generic
   anti-symmetry conjunct) — not defects, but exactly the kind of
   precision the record is for, and both are now docstrings.

And the census — not dual-seat itself, but plant-proven under this
protocol — caught the Classical.choice trap live twice (S2 ×6
conjunctive, S4 ×1 disjunctive), the same trap that bit Circle One
twice. Four bites, three authors, zero escapes.

## 3. What it COST (priced, not waved at)

1. **Roughly half the wall-clock.** Each sub-round spent comparable
   effort on seat B + courier + corrections as on seat P. For 161
   theorems the full experiment ran six loops; a prover-only run
   would have shipped the same Lean in perhaps half the sessions.
   The price bought sections 2's five catches plus 187 independent
   confirmations — the exchange rate looks favorable, but it is real.
2. **Protocol overhead compounds.** Pins, plants, restores, letters,
   tracker blocks: ~15 artifacts per sub-round. The PIN-TRACKER
   exists because by S3 the hash population already exceeded what a
   reader could hold. Any adoption should budget for the ledger, not
   just the loop.
3. **The blindness is procedural, and maintaining it costs
   attention.** The courier script does the mechanical stripping,
   but the SEAT discipline — writing the verifier from statements
   only, choosing routes the statements don't suggest — is a
   standing act of will inside one substrate. It held for six rounds;
   the honest price is that nothing but discipline made it hold.
4. **Prose classes gained nothing.** The corrections letters, the
   reports, this file: all row-7 prose, adjudicated by exactly no
   instrument. The dual-seat mode strengthened the mechanical record
   and left the prose frontier exactly where the REGISTER says it is
   (row 8, unadjudicated). Six rounds of green checks can create a
   halo; the halo must not reach the prose.

## 4. What the workshop might ADOPT (proposals, for the seats of record to take or refuse)

Offered from row 7, smallest first. Each is a practice this
experiment ran end-to-end and can hand over as a working pattern, not
a sketch.

- **P1 — the design probe as a named step.** Before any Lean, a probe
  computes the round's expected structure against bench and
  certificates. The experiment's two clean first censuses (S5, S6)
  both followed probes; the ALARM rounds (S2, S4) preceded the
  practice hardening. Cheap, mechanical, and it moves defects
  upstream of the kernel. Candidate wording: *"a section's forcing
  structure is measured before it is proven."*
- **P2 — the mechanical courier.** Proof-stripped, sha256-pinned,
  re-extraction byte-identical. It removes the hand from the one leg
  of the loop where a hand could silently smuggle proof knowledge
  across the seat boundary. `courier/extract_statements.py` is in
  the tree and is 80 lines.
- **P3 — the omega hygiene rule, promoted from lore to check.** The
  trap has now bitten four times across three authors and two
  circles. The census catches it — but only after the fact. A
  one-line grep gate (flag `omega` applied to goals containing `∧` or
  `∨` in the pre-census transcript, or simply: census runs BEFORE
  ship, always, which this experiment already treats as law) would
  make the fifth bite impossible rather than merely fatal.
- **P4 — the division-of-labor label, stated before the second seat
  runs.** S6's honest label (ranks m ≥ 3 are seat B territory)
  declared the split BEFORE verification, so agreement could not be
  retro-fitted. Wherever kernel and instrument split a claim, the
  split should be written down first. This is norm 6 sharpened by a
  tense.
- **P5 — the register row for single-architecture dual-seat
  deliverables** (standing proposal from the S1 report, restated
  once, unchanged): adjudicator = both seats' instruments PLUS one
  true-stranger pass before "verified" attaches. This experiment is
  the feeder, never the substitute. The S1 report proposed it; six
  rounds later the proposal is unchanged because the boundary it
  prices — one substrate, both chairs — is unchanged.

## 5. The one thing the retrospective owes the record

The experiment's green run could be read as evidence the dual-seat
mode is SUFFICIENT. It is not, and the strongest internal evidence is
the catch distribution: every catch in section 2 was mechanical or
statement-adjacent. **No catch was a characterization slip** — the
species the REGISTER predicts for prose (row 8's standing
prediction), the species one substrate is most likely to commit
identically in both chairs, and therefore the species this protocol
is structurally least able to see. Zero catches there is compatible
with zero defects — and equally compatible with a shared blind spot.
The record should hold both readings until a true stranger reads the
prose. That is not modesty; it is the register-age law applied to
this seat's own output.
