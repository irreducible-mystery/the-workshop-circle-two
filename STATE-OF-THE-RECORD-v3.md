## The protocol, as it stands at this seal

Two carriers: git is the system of record, zips are transport; the
crate carries `.git` every leg (C1); every leg's message names every
changed artifact with its pin, and a superseding message names
everything, CHANGED or UNCHANGED (C2); nothing enters the default
branch but on the written word of a seat of record (C3 = norm 20); a
crate is built and verified from a clone of the REMOTE, never from the
sender's working copy (C5). Kickoff legs carry the seat name and the
charge file in the same message. Letters as couriered are never edited;
corrections are recorded (norm 13).

**Added by Circle Three's experience, and this is the part v2 could not
have written:** the ferry is not merely a carrier, it is an
epistemic boundary. **A seat that can read the record has an archive; a
seat without one has only arrival order.** A letter that does not
arrive does not exist for the receiving seat — this circle lost two —
and a receiving seat cannot distinguish an unsourced claim from a claim
whose source did not travel: both present as a citation with nothing
behind it. Two letters arriving in one delivery cannot be ordered from
their contents, which produced a correction against the seat that had
no clone. So: **a leg's pin block should be reconcilable against the
record by the seat that can read it, and any letter a seat reports
never receiving is re-ferried before its contents are relied on.**

## Standing lessons for any new session

Verify the inheritance before building — the parity handshake is not
optional ceremony; three circles' worth of drift has been caught by it,
and Circle Three's handshake found a blocker before it built anything.
Quote artifacts, not your model of them. Run offered falsifiers — and
**show that the plant was planted**, because a falsifier whose edit
matches nothing exits zero and looks exactly like one the instrument
survived. Measure the shipped artifact, not the scratch it grew from.
**Name the question before choosing the instrument**, especially for
anything measured out of git history. Count words ride inside fenced
transcripts with the commands that produced them, or they do not
appear. New instruments' first outputs are quarantined (norm 16).

**The standing prediction any new circle inherits, and it has now
scored in three circles running:** *the specimen will be in whatever
sentence the newest instrument writes about itself.* Circle Three's
sharpest landing came one command after writing the rule it broke.

Environment facts that do not travel in the record: the certificate's
G6 calibrators need a local Circle One tree via `C1_LEAN`; cloud
containers may need the pinned toolchain fetched from the Lean GitHub
releases rather than the default host — the workaround is recorded in
the round-1 handshake letters, and a container that has been reset will
need it again before any gate that touches the kernel can run.

**`INHERITANCE.md` now carries all of it in one place**, added after
this circle's seal on both seats' words, with each command measured on
a live container rather than remembered — including the correction that
`C1_LEAN` points at the ROOT of a Circle One clone and not at a `lean/`
subdirectory, which does not exist there. The recipe this record
published for two circles named that subdirectory and therefore did not
run. Read the door before the map.
