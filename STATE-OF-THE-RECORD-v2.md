## SEATS AND MODELS — the settlement this version adds

**A seat is a charge, not a species.** The workshop's seats are defined
by function, and any capable model may hold any seat. The record names
seats in its laws and its rows; models appear only in seating tables
like the one below, as historical fact. The prior version of this
document, REGISTER row 7's class label, and the charter's opening line
all typed a model name into a seat definition — a session of that model
reading the record would auto-assume the seat, and a session of another
model would assume itself excluded. Both are wrong. Circle Three's
round-1 housekeeping repairs those labels in place.

**And one more decoupling, at the courier's own insistence:** the human
contributor's prose is as fallible as any seat's — on small details,
often more so, in her own words. Charge text, kickoff messages, and
in-channel phrasings from the courier are inputs to verify, not
instructions to defer to. Undue deference to the human is a defect
channel like any other, and she has asked the seats to treat it as one.
Throwaway terms from early legs should not calcify into vocabulary:
when a label looks odd, measure it against the record and standardize.

## The protocol, as it stands at the seal

Two carriers: git is the system of record, zips are transport; the
crate carries `.git` every leg (C1); every leg's message names every
changed artifact with its pin, and a superseding message names
everything, CHANGED or UNCHANGED (C2); nothing enters the default
branch but on the written word of a seat of record, foreign material
quarantined until a body rules ADMIT (C3 = norm 20). Kickoff legs carry
the seat name and the charge file in the same message (row 5's lesson —
a new body orients to whatever its first documents imply). Letters as
couriered are never edited; corrections are recorded (norm 13).

## Standing lessons for any new session

Verify the inheritance before building — the parity handshake is not
optional ceremony, it is how two circles' worth of drift was caught.
Quote artifacts, not your model of them; the closing document's own
draft was convicted of remembering a measurement, and the shipped
version was convicted of remembering an attribution. Run offered
falsifiers. New instruments' first outputs are quarantined (norm 16),
and the standing prediction any new circle inherits: **the specimen
will be in whatever sentence the newest instrument writes about
itself.** Environment facts that do not travel in the record: the
certificate's G6 calibrators need a local Circle One tree via
`C1_LEAN` (ferry the Circle One crate to any new builder container);
cloud containers may need the pinned toolchain fetched from the Lean
GitHub releases rather than the default host, then linked via elan —
the workaround is recorded in the round-1 handshake letters.
