# THE SYSTEM RECORD — the protocol layer between circles

*This directory is the workshop's system-level record: the ledger of
what happens AT the boundaries between circles, where three circles of
hardened interiors have pushed every remaining defect. It holds
crossing transcripts, the system norms, the system register, and the
commitments (never the texts) of blind predictions. Treat every line as
a pointer to verify, not a fact to trust — the law of the circles is
the law here too.*

## WHO NEEDS THIS, AND WHO MUST NOT

**Nobody who builds inside a chartered circle may need this
directory.** A working seat's world is its own repository, its crates,
its charge, and its door. If a chartered circle's work ever comes to
depend on a file here, that dependency is a defect of THIS record and
is filed on its own register.

Who does read it: the courier-and-principal, outgoing seats whose
circles have sealed (sealing ends a circle seat and vests a system
seat), and incoming seats at a crossing — for the crossing's artifacts
only.

**What must never live here while this directory sits inside a
repository working seats can read: blind-prediction TEXTS.** The
commitment scheme is a hash commitment — the prediction's pin is
published in a closing document, the text is withheld until the next
close, revealed, verified against the pin, then scored. Until the
system record moves to a repository outside every working seat's read
path, the texts stay with the courier and only the pins appear
anywhere in git.

## CUSTODY — interim, and declared as such

This directory is the system record's founding custody, not its final
address. The founding attempted a fresh private repository
("the-workshop-system") and the write path refused it — the measured
result rides in the founding letter — so the record founds where the
founding seat can write, with the move-path stated:

1. The principal creates the private repository from the GitHub UI.
2. The system prover moves this directory there, byte-exact, with this
   history noted, and the copy here becomes a pointer.
3. Blind-prediction texts may live there and never here.

Nothing about the interim custody weakens the ledger: pins are pins
wherever the file sits.

## THE FILES

| path | what it is |
|---|---|
| `SYSTEM-NORMS.md` | The system norms, numbered in their own space (S1, S2, …) so the circles' frozen canons are never touched. Every norm cites its specimen. |
| `SYSTEM-REGISTER.md` | The system register: crossing-specimen rows, two-sided, each naming its witness. Founded at the three-to-four crossing. |
| `crossings/three-to-four/` | The first crossing with a ledger: the artifacts of the Circle Three → Circle Four handoff, byte-exact at their couriered pins, and the founding letters. |

## THE ONE-SENTENCE REASON THIS EXISTS

Prose defects migrate to the nearest unguarded surface; three circles
hardened every interior; the inter-circle boundary was the last
unguarded surface, it grew with every seal, and a specimen caught there
had no ledger and no adjudicator — the sealed register closed behind
it, the next register not chartered ahead of it, and chat transcripts,
the medium this record trusts least, doing its most important storage.
This record is the ledger. The gates come later, built by whoever runs
the next crossing with these rows in hand — capture now, mechanize
later, because specimens in chat transcripts are perishable and law
follows receipts.
