## 3. THE SPECIES NOTE — beside the second pointer exemption

`audit/c2_pointers_exempt.txt` carries an exemption for
`floor/__pycache__/`, a path named in the builder's handshake letter's
norm-16 plant table. The entry records the cost. This note records why
the cost was invisible, and it is the better finding of the two:

**The builder's own gating pass was green for a reason that does not
travel.** Running the floor benches during the plants made Python
recreate the planted cache directory on that container's filesystem as
an import side effect, so the token resolved there — and resolves in no
fresh clone. That is C5's exact species, occurring **inside the gating
pass whose purpose was catching that species**, and caught by the
receiving seat rather than the sending one.

The lesson generalizes past the entry: *an instrument can be green
because of a side effect of running a different instrument.* Nothing in
the current chain checks for that.
